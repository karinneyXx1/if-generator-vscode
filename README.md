# IF Generator - VS Code Extension

Плагин для автоматической вставки IF-блоков в код C/C++, JavaScript, TypeScript и других языков.

## 👨‍💻 Автор
**Гатиатуллина Карина Наилевна М3100**

### Установка
1. Установите расширение из файла `if-generator-1.0.0.vsix`
2. Или соберите из исходников: `npm install && npm run package`

### Использование
- **Ctrl+Shift+I** - вставить IF-блок
- Или через палитру команд (Ctrl+Shift+P) → "Insert IF block"
