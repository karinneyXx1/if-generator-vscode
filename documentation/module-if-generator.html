Module: if-generator

Плагин позволяет быстро вставлять шаблоны IF-условий в код JavaScript, TypeScript и других языков. После вставки курсор автоматически позиционируется на месте условия для быстрого редактирования.

Как использовать плагин

1. Установите расширение в VS Code
2. Откройте любой файл с кодом
3. Нажмите Ctrl+Shift+I 
4. Или вызовите команду через палитру (Ctrl+Shift+P) → "Insert IF block"
5. Будет вставлен шаблон IF-условия с курсором на месте условия

Examples

Базовое использование

// Исходный код:
function example() {
    console.log("test");█
}

// После вызова insertIf:
function example() {
    if (condition) {
        █
    }
    console.log("test");
}

Вставка в середине кода

// До:
const array = [1, 2, 3];
array.forEach(item => {█
    console.log(item);
});

// После:
const array = [1, 2, 3];
if (condition) {
    █
}
array.forEach(item => {
    console.log(item);
});

Редактирование условия

// После вставки просто начните печатать чтобы изменить условие:
if (user.isAdmin) {          // Замените "condition" на нужное условие
    console.log("Admin access");
    █                        // Курсор автоматически позиционируется здесь
}

Использование с другими конструкциями

// Можно комбинировать с else:
if (condition) {
    █
} else {
    // код для else
}

// Или с else if:
if (condition) {
    █
} else if (anotherCondition) {
    // другой код
}
