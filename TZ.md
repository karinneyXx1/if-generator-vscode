# Плагин "Генератор IF-блоков" для VS Code

## 1. Назначение и цель
**Плагин для автоматической вставки шаблонов IF-выражений в VS Code**

Цель: Ускорить написание кода на C++ за счет автоматизации рутинных операций

## 2. Функциональные требования

### 2.1 Основная функциональность
- Вставка шаблона `if (condition) {}` по горячей клавише
- Автоматическое позиционирование курсора внутри блока
- Визуальное подтверждение операции

## 3. Технические требования

### 3.1 Совместимость
- VS Code версии 1.74.0 и выше
- Операционные системы: Windows, Linux, macOS
- Языки программирования: C++, C

### 3.2 Производительность
- Вставка шаблона должна происходить мгновенно
- Плагин не должен замедлять работу VS Code

## 4. Требования к работоспособности
- При нажатии `Ctrl+Shift+I` вставляется шаблон IF
- Курсор позиционируется внутри блока
- Показывается уведомление "IF statement inserted!"
- Плагин работает в файлах .cpp и .c
